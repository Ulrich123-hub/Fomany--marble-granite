To publish with GitHub Pages:
1. Create a new PUBLIC GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. GitHub will provide the website URL.

Important:
The catalogue also contains several external image URLs for Nigerian project/showroom reference images. The site can still load them while online, but for maximum reliability you can later replace those external URLs with original Fomany photos.
